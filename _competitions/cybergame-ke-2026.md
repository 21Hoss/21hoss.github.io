## About

**CyberGame KE 2026** is a ten-week Kenyan cybersecurity challenge running
from **March 1** to **May 9, 2026**. Each week opens a new track:

| Week | Track                  |
| ---- | ---------------------- |
| 1    | OSINT & recon          |
| 2    | Cryptography           |
| 3    | Web exploitation       |
| 4    | Digital forensics      |
| 5    | Reverse engineering    |
| 6    | Binary exploitation    |
| 7    | Incident handling      |
| 8    | Malware analysis       |
| 9    | Network forensics      |
| 10   | Free-for-all finals    |

I'm playing this **solo**, with the express goal of shipping a write-up per
challenge.
